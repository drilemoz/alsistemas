Permissões

O gerenciador identifica o proprietário da pasta e os arquivos elegíveis. Você escolhe até 12 arquivos e a conta PHP, salva a seleção e depois libera a escrita ou restaura os modos e grupos anteriores.

A seleção não concede escrita automaticamente. A conta PHP escolhida precisa corresponder ao pool real do domínio. A instalação de testes, links simbólicos, segredos e caminhos fora do projeto continuam protegidos.

Atualizações do portal

ZIP: escolha um pacote compatível e mais recente, com até 32 MiB. GitHub: informe proprietário/repositório de uma Release pública. Ambos atualizam o código de produção.

Banco de dados e uploads não são alterados; a atualização cria backup do código. Em andamento, a instalação pode reiniciar serviços. Aguarde o resultado e consulte Histórico se ocorrer falha.

Sobre backups e restauração

Criar backup salva uma cópia privada do código. Restaurar substitui os arquivos da produção pela cópia selecionada. A restauração é uma ação potencialmente destrutiva e exige confirmação.

Estas cópias não incluem banco de dados e arquivos enviados. Para recuperação integral da VPS, considere snapshot EBS e backup separado do banco e dos uploads.

O SHA-256 confirma a integridade dos bytes verificados. Ele não testa a frase secreta e não substitui um teste de restauração.

Como ler o histórico

O painel mostra eventos administrativos recentes, com resultado, horário e motivo de falhas, quando registrado. A última atualização é apresentada separadamente.

A lista apresenta somente eventos disponíveis no AL Sistemas, não o journal completo do systemd. No botão Relatório técnico você pode consultar/copiar/baixar o conteúdo bruto; revise informações sensíveis antes de compartilhar.

TUTORIAL PASSO A PASSO
Configurar Spaceship API
  1. Acesse sua conta na Spaceship e abra o API Manager oficial.
  2. Crie uma API Key e copie a API Secret. Guarde a Secret em local seguro: ela pode não ser exibida novamente.
  3. Conceda a permissão dnsrecords:read para consultar DNS. Para adicionar e editar TTL ou excluir registros, habilite também dnsrecords:write.
  4. Abra Gerenciar, informe a API Key e a API Secret e toque em Salvar credenciais.
  5. Toque em Testar DNS, informe um domínio cujo DNS é administrado na Spaceship e selecione Testar e consultar.
  6. As alterações de DNS exigem sessão autenticada, prévia e confirmação. Nomes essenciais são protegidos. Se aparecer HTTP 401/403, revise as credenciais, permissões e eventuais restrições de IP. Se o domínio não aparecer, verifique se o DNS dele é administrado pela Spaceship.
As credenciais nunca devem ser enviadas por chat ou incluídas em arquivos do GitHub. Salvar não testa automaticamente a conexão.

COMO ENTENDER
Sobre o diagnóstico
Esta tela faz uma análise de leitura. Ela não corrige, altera nem libera permissões.
  • Arquivo encontrado significa somente que ele existe e foi verificado como arquivo regular.
  • Sem escrita PHP é uma estimativa baseada no usuário do pool PHP padrão. Não identifica obrigatoriamente o pool usado pelo domínio.
  • Operação bloqueada significa que a verificação de propriedade impediu uma alteração administrativa automática.
  • Permissão temporária só é concedida na tela Arquivos, após confirmação.
A vistoria não substitui testes reais do PHP, MySQL e da configuração do Nginx.
