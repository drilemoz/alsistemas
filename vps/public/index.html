TUTORIAL PASSO A PASSO

Configurar Spaceship API

  1. Acesse sua conta na Spaceship e abra o API Manager oficial.
  2. Crie uma API Key e copie a API Secret. Guarde a Secret em local seguro: ela pode não ser exibida novamente.
  3. Conceda a permissão dnsrecords:read para consultar DNS. Não habilite dnsrecords:write nesta versão.
  4. Insira a API Key e a API Secret nesta tela e toque em Salvar / substituir.
  5. Informe um domínio cujo DNS é gerenciado pela Spaceship e toque em Testar conexão e consultar DNS.
  6. Se aparecer HTTP 401/403, revise as credenciais, permissões e eventuais restrições de IP. Se o domínio não aparecer, verifique se o DNS dele é administrado pela Spaceship.

As credenciais nunca devem ser enviadas por chat ou incluídas em arquivos do GitHub. Salvar não testa automaticamente a conexão.
