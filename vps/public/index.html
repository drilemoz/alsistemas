TUTORIAL PASSO A PASSO
Configurar Spaceship API
  1. Acesse sua conta na Spaceship e abra o API Manager oficial.
  2. Crie uma API Key e copie a API Secret. Guarde a Secret em local seguro: ela pode não ser exibida novamente.
  3. Conceda a permissão dnsrecords:read para consultar DNS. Para adicionar e editar TTL ou excluir registros, habilite também dnsrecords:write.
  4. Abra Gerenciar, informe a API Key e a API Secret e toque em Salvar credenciais.
  5. Toque em Testar DNS, informe um domínio cujo DNS é administrado na Spaceship e selecione Testar e consultar.
  6. As alterações de DNS exigem senha administrativa, prévia e confirmação. Nomes essenciais são protegidos. Se aparecer HTTP 401/403, revise as credenciais, permissões e eventuais restrições de IP. Se o domínio não aparecer, verifique se o DNS dele é administrado pela Spaceship.
As credenciais nunca devem ser enviadas por chat ou incluídas em arquivos do GitHub. Salvar não testa automaticamente a conexão.
